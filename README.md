# Большая грузинская кухня — сайт сети ресторанов

Одностраничный сайт сети «Большая грузинская кухня» (Санкт-Петербург, 3 адреса),
собранный по навыку `design-taste-frontend` (taste-skill).

Возможности:

- **Бронирование стола** в любом из трёх ресторанов (форма с валидацией, код заявки,
  сохранение в API и localStorage);
- **Меню с картинками блюд**: лента фотографий хитов + 11 разделов официального меню
  с весами и ценами (единая цена 290/350 ₽, PRIME, гарниры, соусы, обеды);
- **Как выглядит каждый ресторан**: карточки адресов и модалка с галереей интерьера,
  особенностями, отзывами с Яндекс Карт и маршрутом;
- **Контакты**: телефоны, часы работы, метро, ВКонтакте.

## Стек

Vite + React + TypeScript, Tailwind CSS v4, Motion (`motion/react`),
`@phosphor-icons/react`, шрифты Golos Text + Playfair Display (self-hosted, кириллица).

## Запуск

```bash
npm install
npm run server   # API бронирований на :4321 (без зависимостей, пишет server/bookings.json)
npm run dev      # сайт на :5173, /api проксируется на :4321
```

Без запущенного API сайт продолжает работать: заявка сохраняется локально
и подтверждение показывается в любом случае.

## Проверка

```bash
npm run build      # tsc + vite build
node scripts/e2e.mjs   # smoke-тест в headless Chromium (нужны dev и server)
```

## Данные и ассеты

Контент собран из официального меню сети и карточек Яндекс Карт
(адреса, телефоны, часы, метро, рейтинги, отзывы). Исходные фотографии
оптимизированы в WebP и лежат в `public/img` (7.5 МБ суммарно).
